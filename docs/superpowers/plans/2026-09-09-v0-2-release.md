## Global Constraints

- Use Next.js 15.5.25 or a later patched 15.5 Maintenance LTS release; do not jump to Next 16 without a technical need.
- Product version is exactly `0.2.0`; do not change demo agent, dataset, dependency, or migration versions as product metadata.
- Preserve OpenAI Responses integration and never make a real OpenAI request.
- Require zero unresolved high or critical dependency advisories when compatible fixes exist.
- Never commit secrets, `.env`, demo runtime reports, database files, logs, or unsafe screenshots.
- Never force push, publish to PyPI, or publish container images.
- Tag and release only the final commit with green GitHub CI.
