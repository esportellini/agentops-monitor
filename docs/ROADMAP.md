# Roadmap

## v0.2 — Real providers
- Anthropic provider for evaluation runs
- Streaming support in ingest API
- Webhook notifications for alert incidents
- Slack / email notification channels

## v0.3 — Advanced analytics
- Cost anomaly detection (statistical baseline)
- Agent performance trends over time
- Token efficiency analysis
- Comparative latency percentiles (p50/p95/p99)

## v0.4 — Compliance
- SOC 2 audit log export
- GDPR addendum alongside LGPD
- Data residency configuration
- Encryption at rest (field-level for PII)

## v0.5 — Collaboration
- Comments on findings and traces
- Runbook attachments
- Shared evaluation datasets across projects
- Public API documentation (OpenAPI-generated)

## v1.0 — Enterprise
- SSO (SAML, OIDC)
- Custom roles
- Organization hierarchy (parent/child orgs)
- SLA monitoring
- On-premises deployment guide
